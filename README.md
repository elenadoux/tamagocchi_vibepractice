# Tama — pocket music companion

Локальный 3D-плеер с оригинальным пиксельным питомцем Pip. Один полупрозрачный розовый корпус, React + TypeScript + Vite + Three.js / React Three Fiber / Drei. Сервер, аккаунты и внешние сервисы не нужны.

## Запуск

Из этой папки:

```sh
npm install
npm run dev
```

Откройте адрес Local, который напечатает Vite. Плеер стартует на паузе; звук включается только после вашего нажатия.

```sh
npm run build
npm run preview
```

`dist/` — готовая сборка. `index.html` следует открывать через HTTP-сервер, не двойным кликом.

## Музыка

Исходная папка `tracks/` сохранена. Плеер автоматически подхватывает MP3, WAV, OGG, M4A, FLAC из неё. Рекомендуемое название: `Artist - Title.mp3`. После добавления файла перезапустите dev-сервер; для готовой сборки заново выполните `npm run build`. Поддержка конкретных аудиокодеков зависит от браузера.

## Управление

- На главном экране: слева предыдущий трек, в центре play/pause, справа следующий.
- Удерживайте центральную кнопку 600 мс, чтобы открыть меню. Отпускание после удерживания не переключает воспроизведение.
- В меню: слева следующий пункт, в центре выбрать, справа назад.
- Меню можно открыть и кликом на ноту в верхнем левом углу LCD.
- Клик по названию открывает сведения о треке; там можно добавить его в избранное. Полоса прогресса перематывает трек.
- Space — play/pause; стрелки — действия боковых кнопок; M — меню; Escape — назад; Enter — выбрать. Tab позволяет сфокусировать кнопки и настройки.
- В настройке громкости левая кнопка добавляет 10% с переходом после 100% к 0%; ползунок даёт точную регулировку. Центральная возвращает назад.
- На паузе после 45 секунд бездействия Pip засыпает. Действие мышью, касание или клавиша его будят.

Избранное, громкость и контраст сохраняются только в localStorage этого браузера. Смена цвета, эффекты обработки звука, выбор персонажа и игровой симулятор не входят в этот MVP.

## Архитектура

- `src/components/TamagotchiDevice.tsx`: лёгкая процедурная модель с вырезом для экрана, пластиковый материал, освещение, металлическое кольцо, инерционный наклон и отдельные подвижные 3D-кнопки. LCD и семантические кнопки встроены через трансформированный Drei Html и наклоняются вместе с корпусом.
- `src/components/LCDScreen.tsx`: домашний экран, меню, треки, избранное, питомец, визуализации, настройки и детали трека.
- `src/audio/AudioEngine.ts`: один HTMLAudioElement и один AudioContext, транспорт и частотный анализ. Анализатор не вызывает React-перерисовку на каждом кадре; метрики передаются через изменяемый объект.
- `src/character/characterFrames.ts`: оригинальные 32×32 растровые спрайты, четыре кадра для каждого из семи состояний.
- `src/character/characterAnimations.ts`: выбор реакции на энергию/бас с cooldown.
- `src/character/PixelCharacter.tsx`: canvas с отключённым сглаживанием, ступенчатые анимации и визуализации.
- `src/hooks/usePlayerUI.ts`: навигация, сон, локальные настройки, клавиатура.
- `src/config.ts`: единые настройки взаимодействий. `DEBUG` по умолчанию выключен.

Отсутствуют внешние HDRI и сетевые шрифты: освещение построено локально, шрифт поставляется со сборкой. Мобильный наклон отключён; поддерживается reduced motion. При ошибке трека LCD предлагает следующий трек. WebGL требует аппаратного ускорения браузера.
